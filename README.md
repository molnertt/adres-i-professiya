# Адрес сменился. Профессия — нет

Интерактивный лендинг концепции кампании в поддержку «Ночлежки». Сайт рассказывает о профессиональном опыте людей, столкнувшихся с бездомностью.

## Что внутри

- карточка Анны Сергеевны с интерактивным ползунком;
- истории людей разных профессий;
- раскрывающиеся этапы помощи;
- адаптивная вёрстка для компьютера и телефона.

Сайт статический: откройте `index.html` в браузере. Для публикации через GitHub Pages достаточно выбрать корень основной ветки как источник сайта.

Кнопки поддержки ведут на [официальную страницу «Как помочь»](https://homeless.ru/how_to_help/) «Ночлежки». Имена и изображения героев приведены для примера. Этот репозиторий — визуальный концепт, а не официальный сайт организации.
