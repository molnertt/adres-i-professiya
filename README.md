# Адрес сменился. Профессия — нет

[Открыть сайт на GitHub Pages](https://molnertt.github.io/adres-i-professiya/)

Лендинг концепции кампании в поддержку «Ночлежки». Он показывает профессиональный опыт людей, столкнувшихся с бездомностью. «Иван Васильевич меняет адрес» — название кампании; истории на сайте посвящены людям разных профессий.

## На сайте

- визитки людей четырёх профессий;
- передвижная линия между опытом человека и тем, что ему нужно сейчас;
- объяснение, как помогает Ночлежка;
- адаптивная версия для компьютера и телефона.

Сайт статический. Кнопки поддержки ведут на [официальную страницу «Как помочь»](https://homeless.ru/how_to_help/) «Ночлежки».

Имена и изображения героев приведены для примера. Этот репозиторий — визуальный концепт, а не официальный сайт организации.

Для названия кампании используется шрифт Neucha (Jovanny Lemonad); лицензия SIL Open Font License находится в `OFL-Neucha.txt`.
